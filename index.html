TUDO SOBRE PROGRAMAÇÃO

Vou compartilhar curiosidades sobre a disciplina de Programação e IA

PRIMEIRA LINGUAGEM: P5.JS

Por: daniel junior

O p5.js é uma biblioteca de JavaScript criada para tornar a programação visual acessível e divertida para artistas, designers, educadores e iniciantes.

SEGUNDA LINGUAGEM:HTML

Por: daniel junior

HTML (HyperText Markup Language, ou Linguagem de Marcação de Hipertexto) é a linguagem de marcação padrão utilizada para criar e estruturar páginas na web.

TERCEIRA LINGUAGEM: CSS

Por: daniel junior

O CSS (Cascading Style Sheets ou Folhas de Estilo em Cascata) é uma linguagem de estilo usada para definir a aparência visual de páginas na internet.

QUARTA LINGUAGEM: JAVASCRIPT

Por: daniel junior

O JavaScript (frequentemente abreviado como JS) é uma linguagem de programação de alto nível, interpretada e orientada a objetos. Junto com o HTML e o CSS, ele forma a base da World Wide Web, sendo responsável por dar dinamismo e interatividade às páginas da internet.

QUINTA LINGUAGEM: PYTHON

Por: daniel junior

O Python é uma linguagem de programação de alto nível, interpretada, de código aberto e propósito geral, criada por Guido van Rossum em 1991. Saiba mais na Documentação Python ou confira uma visão geral na AWS e na Oracle.
